Командууд

Slash командуудыг Discord-ийн command picker-ээс ашиглана. Administrator болон owner-д зориулсан хэсгүүд тусдаа эрхтэй.

Эхлэхэд хэрэгтэй:

/help командаар bot доторх бүх тусламжийг харна. /usersettings-ээр DM болон read receipt тохиргоогоо өөрчилнө.

Prefix команд: ?protect — 3 цагийн хамгаалалт идэвхжүүлнэ.

Түгээмэл
асуултууд.

Хариулт олдохгүй бол support server-ээс асууж болно.

MessAge яг юу хийдэг вэ?

MessAge нь Discord дээр хэрэглэгч хоорондын хувийн зурвас (DM) дамжуулах, хамгаалалт, cooldown, report болон appeal урсгалыг зохицуулдаг bot юм. Дэлгэрэнгүйг Командууд хэсгээс харна уу.

Bot-ыг серверт хэрхэн нэмэх вэ?

Дээрх "Bot нэмэх" товчийг дарж, зурвас илгээх зөвшөөрөл өгөх серверээ сонгоно. Аккаунт үүсгэх, нэвтрэх шаардлагагүй — Discord дотроосоо шууд ажиллана.

Надад тодорхойгүй хүнээс DM ирж байвал яах вэ?

Ирсэн зурвасны доорх 🛡️ "Хамгаалалт авах" товч эсвэл ?protect командаар 3 цагийн турш өөрийгөө /priv зурвасаас хамгаална. Мөн /usersettings-ээр DM бүрмөсөн унтраах боломжтой.

Зохисгүй зурвас ирвэл яах вэ?

Зурвасны доорх 🚩 "Мэдээлэх" товчоор шалтгаанаа сонгож report хийнэ. Явцыг /myreports-оор дагаж болно. Bot owner report-ыг шалгаж шийдвэр гаргана.

Хориг авсан бол яах вэ?

/appeal командаар гомдол гаргаж болно. Явцыг /myappeals-оор харна. Owner-ийн шийдвэр эцсийн шат байх бөгөөд дэлгэрэнгүйг Terms of Service-оос харна уу.

Bot ямар мэдээлэл хадгалдаг вэ?

User ID, тохиргоо, usage metadata болон report/appeal-тай холбоотой мэдээлэл SQLite database-д хадгалагдана. Дэлгэрэнгүйг Privacy Policy-оос харна уу.

Bot ажиллахгүй байх шиг байна, яах вэ?

Status хуудаснаас hosting endpoint онлайн эсэхийг шалгаад, асуудал үргэлжилвэл support server-ээр мэдэгдээрэй.
